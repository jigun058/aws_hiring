## 1. 개요

고용24 국민내일배움카드 훈련과정 6,122개의 데이터를 중복 제거해 3,173개로 정리하고 채용공고 데이터와 같은 역량 키워드 사전으로 태깅해 직무 810개와 연결했다. 그 결과 과정의 97.9%(3,105개)가 하나 이상의 직무와 연결되었다.

CareerLens의 "부족 역량 → 교육과정 추천" 단계를 위한 데이터 기반을 만드는 과정이다. 채용공고와 교육과정이 같은 키워드 번호를 쓰기 때문에, "직무가 요구하는 키워드 − 사용자가 가진 키워드 = 부족 역량"을 계산한 뒤 그 키워드가 붙은 과정을 바로 찾을 수 있다.

## 2. 원천 데이터 수집

고용24 OPEN-API(국민내일배움카드 훈련과정 목록)를 Python 스크립트로 호출해 CSV로 저장했다. 고용24 API는 한 번 요청에 최대 100건까지만 돌려주기 때문에 100건씩 나눠 62번 요청해 전체 6,122건을 받았다.

원본에서 추천에 쓸 수 있는 컬럼과 비어 있는 컬럼은 다음과 같다. 과정 설명이 없어서 태깅은 과정명과 NCS 코드에 의존한다.

(이미지 1 전사)

| 구분 | 컬럼 | 비고 |
| --- | --- | --- |
| 태깅 근거 | `title` (과정명), `ncsCd` (NCS 8자리 세분류, 211종) | 빈값 없음 |
| 화면 표시 | `subTitle` (기관), `traStartDate` · `traEndDate`, `realMan` (훈련비), `address`, `titleLink` | 빈값 없음 |
| 식별자 | `trprId` + `trprDegr` | 두 값을 합치면 고유 키 |
| 비어 있음 | `contents` (과정 설명), `grade`, `eiEmplRate3` · `eiEmplRate6` (취업률) | 100% 빈값 |
| 거의 비어 있음 | `certificate` (관련 자격증) | 99% 빈값 |

## 3. 전처리 단계

전처리는 6단계로, 과정 3,173개를 하나씩 태깅하지 않고 NCS 소분류 96개 단위로 태깅한 뒤 과정명 규칙으로 보정한 것이다. 작업량을 약 1/30로 줄이면서 결과를 일관되게 유지할 수 있다.

1. **타입 고정과 중복 제거.** 모든 컬럼을 문자열로 읽어 NCS 코드·지역코드의 앞자리 0을 지켰다. 과정명+훈련기관 기준으로 6,122회차를 과정 3,173개로 묶고, 회차별 시작일·종료일·훈련비·지역·링크는 과정 안의 회차 목록(sess)으로 보관했다.
2. **공통 키워드 사전 적용.** 채용공고 DB의 키워드 178개(8개 역량 분류)를 순서까지 그대로 가져왔다. 새 키워드는 만들지 않았다.
3. **NCS 매핑표 (출처 N, 점수 0.6).** 과정에 나오는 NCS 소분류(6자리) 96개마다 분야명과 관련 키워드를 지정했다. 예: 130101 조리 → 조리 · 조리 지식 · 조리 기구 활용 · 영양·식품위생 지식 · 위생 관리. 같은 소분류의 과정은 모두 같은 기본 키워드를 받는다.
   - 교육과정의 NCS 코드마다 키워드를 할당하기 때문에 같은 NCS 코드를 가지고 있는 교육과정에 같은 키워드를 받게 됨
4. **과정명 규칙 (출처 T 0.8 / C 0.7).** 정규식 규칙 약 70개로 과정명에서 자격증(요양보호사, 컴퓨터활용능력, 전산회계, 지게차운전기능사 등)과 도구·업무(엑셀, 포토샵, 파이썬, 영상편집 등)를 찾아 키워드와 자격증 목록(cert)으로 바꿨다. "(사회복지사 등 자격증소지자)"처럼 수강 조건을 나타내는 괄호는 규칙 적용에서 제외했다.
   - *(N = NCS, T = 과정명, C = 자격증). '점수 0.6'은 그 근거를 얼마나 믿는지
5. **연관도 합산.** 한 키워드에 근거가 여러 개면 아래 식으로 합쳐 근거가 많을수록 점수가 1에 가까워지게 했다. 예: 자격증(0.7) + NCS(0.6) = 0.88.
6. **직무 연결.** 과정 키워드가 각 직무의 핵심 역량(필수·주요 키워드)을 얼마나 덮는지를 적합도로 계산했다. 세부 기준은 아래와 같다.
   - 비교 대상: 교육으로 채울 수 있는 역량(전문지식·도구·업무·관리·분석)만. 소프트 스킬·신체 역량·대인관계는 제외
   - 가중치: 필수 2 · 주요 1 · 보조 0.5
   - 조건: 직무의 필수 키워드 중 하나 이상을 과정이 다뤄야 연결 (원문 표기: "다뤘야")
   - 가산: 과정의 자격증명이 직무명과 같으면 +0.3 (요양보호사 과정 → 요양보호사 직무)
   - 커트라인: 0.3 이상만 연결, 과정당 상위 5개 직무 · 직무당 상위 30개 과정 저장

(이미지 2 전사 — 연관도 식)

```
연관도 = 1 − ∏_i (1 − s_i),   s_i ∈ {0.8(과정명), 0.7(자격증), 0.6(NCS)}
```

(이미지 3 전사 — 직무 적합도 식)

```
직무 적합도 = min( 1,  Σ_{k∈겹침} 연관도_k × w_k  /  Σ_{k∈직무 필수·주요} w_k )
```

## 4. 결과 및 검수

과정 3,173개에 키워드 11,573개가 연결되었고, 3,105개(97.9%)가 직무와 연결되었다. 모든 과정의 NCS 코드가 매핑표에 들어 있어 미매핑은 0건이다.

검수는 공고 수 상위 직무별로 연결된 과정 상위 5개를 직접 확인하는 방식으로 했다. 확인 중 발견한 문제(조리·총무 직무 연결 0건, 수강조건 괄호의 자격증 오추출)는 점수 정규화와 규칙을 고쳐 다시 실행했다.

(이미지 4 전사)

| 직무 (공고 수) | 적합도 상위 과정 | 적합도 |
| --- | --- | --- |
| 요양보호사 (14,798) | 요양보호사 자격 취득과정 | 0.99 |
| 건물 청소원 (2,862) | 청소마스터종합, 정리수납전문가 | 0.72–0.80 |
| 사회복지사 (1,077) | 사회복지사1급 자격증 대비반 | 0.73 |
| 단체급식 조리사 (876) | 한식·양식조리기능사 취득과정 | 0.69 |
| 경리 사무원 (635) | 전산회계·전산세무·ERP 자격과정 | 0.81 |

공고 상위 50개 직무 중 16개는 연결된 과정이 없다. 제조 단순 종사원, 배송·화물차 운전원, CNC·MCT 조작원, 창고 관리원 등 진입 장벽이 낮거나 이번 수집 범위에 해당 훈련이 없는 직무다. 서비스에서는 이 경우를 "교육 없이 바로 지원 가능"으로 분기한다.

## 5. 산출물 구조

개발용 산출물은 courses.json 하나이며, 최상위 키 6개로 구성된다. 용량을 줄이려고 배열은 이름 없이 위치로 값을 담는다.

(이미지 5 전사)

| 키 | 내용 | 원소 형식 |
| --- | --- | --- |
| `kw` | 키워드 사전 178개 (채용공고 DB와 동일) | [키워드명, 역량분류 C1~C8, 가중치] |
| `crs` | 교육과정 3,173개 | 객체 (아래) |
| `occ` | 직무 810개 요약 | [직무ID, 직무명, 직종코드, 대분류, 공고 수] |
| `occCrs` | 직무ID → 맞는 과정 (적합도 순, 최대 30개) | [과정ID, 적합도] |
| `ncs` | NCS 매핑표 | [NCS코드, 분야명, [키워드 번호]] |
| `rules` | 과정명 규칙 (검증용) | [정규식, [키워드 번호], 자격증명] |

과정 하나(crs의 원소)의 필드는 다음과 같다.

(이미지 6 전사)

| 필드 | 의미 |
| --- | --- |
| `id`, `t`, `inst` | 과정ID(CRS0001~), 과정명, 훈련기관 |
| `ncs`, `ncsNm`, `type` | NCS 코드, NCS 분야명, 훈련 유형 |
| `cert` | 관련 자격증 목록 |
| `sess` | 회차 목록: [훈련과정ID, 회차, 시작일, 종료일, 훈련비, 지역, 링크] |
| `k` | 키워드: [키워드 번호, 연관도, 출처(T 과정명 · C 자격증 · N NCS)] |
| `occ` | 연결 직무: [직무ID, 적합도, [근거 키워드 번호]] |

예를 들어 '요양보호사 자격취득과정'(CRS0009)은 노인 돌봄 지식·신체활동 지원·돌봄 서비스를 연관도 0.88(자격증+NCS)로 갖고, 요양보호사 직무(OCC0410)에 적합도 0.99로 연결된다. 검수용 courses_viewer.html은 같은 데이터를 내장해 과정·직무별로 검색해 볼 수 있다.

## 실제 파일과 대조한 값 (가져온 사람 메모)

내려받은 `courses.json`의 최상위 키별 원소 수: `kw` 178, `crs` 3,173, `occ` 810, `occCrs` 489, `ncs` 211, `rules` 63.

- 문서는 "NCS 소분류 96개", "정규식 규칙 약 70개"라고 쓰지만 파일에는 `ncs` 211개, `rules` 63개가 들어 있다. (211은 문서 표의 "NCS 8자리 세분류 211종"과 일치)
- `occCrs` 489개 = 과정이 하나 이상 연결된 직무 수 (810개 중).
