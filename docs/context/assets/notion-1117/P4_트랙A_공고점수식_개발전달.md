> 대상: 구현 담당 · 작성: 로직 담당 · 2026-11-17
> 설계서 v0.2 F7(매칭 점수)을 지금 결정에 맞게 고친 것이다. v0.2 원문은 비공개라 이 문서로 대신한다.

## 1단계. 빼야 할 요구 역량 (꼭 반영)

### 1.1 규칙

공고의 요구 역량 중 아래에 해당하는 것은 **분자와 분모 모두에서 뺀다.**

| 빼는 것 | 판단 방법 | 예 | 화면 처리 |
|---|---|---|---|
| C4 태도·성격 | 사전 `분류코드 = C4` | 책임감, 성실함, 꼼꼼함, 리더십, 학습 능력 | 공고 카드의 "근무 조건·태도 요구"에 표시만 |
| C5 신체·근무조건 | 사전 `분류코드 = C5` | 체력, 중량물 취급, 교대·야간 근무 | 같은 곳에 표시. 필터 정보로만 사용 |
| 사전에 없는 요구 | `unmapped_requirements`에 들어간 것 | Celery, 사내 도구 이름 | "사전에 없는 요구"로 표시 |
| 검토 전 AI 후보 | 요구 역량의 `status = llm_candidate` | — | "확인 중인 요구사항"으로 표시 |

추가 규칙:
- "Python or R"처럼 둘 중 하나를 요구하면 **요건 1개**로 센다. 사용자가 둘 중 하나라도 가졌으면 그 요건을 가진 것으로 본다.
- 같은 역량이 필수와 우대에 모두 있으면 **필수**로 한 번만 센다.
- 사용자 쪽에서도 `llm_candidate`(사용자가 확정하기 전의 AI 후보)는 "가진 역량"으로 세지 않는다.
- 빼고 나서 남은 필수 + 우대가 0개면 점수를 내지 않고 "역량 정보 부족 공고"로 표시한다.

### 1.2 식

```
일치도 = (가진 필수 수 × 2 + 가진 우대 수 × 1) ÷ (필수 수 × 2 + 우대 수 × 1)
         ※ 필수 수·우대 수·가진 수는 모두 1.1의 요구 역량을 뺀 뒤에 센다
```

### 1.3 예시: 빼기 전과 뺀 후

- **공고**
  - 필수: Python, SQL, 책임감(C4), 교대근무 가능(C5)
  - 우대: Tableau, Celery(사전에 없음)
- **사용자:** Python, SQL 보유

| | 필수 | 우대 | 계산 | 일치도 |
|---|---|---|---|---|
| 빼기 전 | 4개 중 2개 | 2개 중 0개 | (2×2 + 0) ÷ (4×2 + 2×1) = 4 ÷ 10 | **40%** |
| **뺀 후** | 2개 중 2개 | 1개 중 0개 | (2×2 + 0) ÷ (2×2 + 1×1) = 4 ÷ 5 | **80%** |

기술 요구를 다 갖췄는데도 태도·근무조건 문구 때문에 40%로 떨어지던 문제가 사라진다.

## 2단계. 근거 계수 곱하기 (권장)

### 2.1 근거 계수 [확정]

경험 카드의 역량마다 붙는 근거 등급(`evidence_level`)에 따라 곱한다. 팀원 엔진의 근거 강도 값과 같다.

| 등급 | 뜻 | 계수 | 팀원 엔진 |
|---|---|---|---|
| L3 | 본인 행동 + 성과가 있음, 또는 유효 자격증 | 1.0 | 성과 있음 1.0 |
| L2 | 본인 행동은 있으나 성과 없음 | 0.75 | 수행 0.75 |
| L1 | 수강·학습만, 도구 이름만 말함 | 0.5 | 학습만 0.5 |
| L0 | 근거 없음 | 0 | — (카드에 저장되지 않음) |

- 사용자가 같은 역량을 카드 여러 장에 가졌으면 **가장 높은 등급** 하나만 쓴다.
- 경험 카드의 연결 방식(direct / derived / transferable)은 근거 등급과 **다른 값**이다. 트랙 A 식에는 근거 등급만 쓴다.

### 2.2 식

```
요건 하나의 충족값 = 근거 계수 (사용자에게 없으면 0)
일치도 = (필수 충족값 합 × 2 + 우대 충족값 합 × 1) ÷ (필수 수 × 2 + 우대 수 × 1)
```

### 2.3 예시

1.3과 같은 공고와 사용자이고, 사용자 근거만 추가했다: Python L2, SQL L3.

```
필수 충족값 합 = 0.75(Python) + 1.0(SQL) = 1.75
우대 충족값 합 = 0(Tableau)
일치도 = (1.75 × 2 + 0) ÷ (2 × 2 + 1 × 1) = 3.5 ÷ 5 = 70%
```

## 3단계. 전체 식 (여유 있을 때)

### 3.1 총점

```
경험 일치도(100점) = 역량 적합도 60 + 직무 일치도 15 + 경력 적합도 15 + 선호 조건 10
```

### 3.2 역량 적합도 (60점)

**요건 하나의 충족값**
```
충족값 = 유사도 계수 × 근거 계수
```

| 유사도 계수 | 값 | 예 |
|---|---|---|
| 같은 역량·같은 기술 | 1.0 | Postgres = PostgreSQL |
| 하위 기술 → 상위 역량 | 0.9 | PostgreSQL 경험 → SQL 요구 |
| 같은 계열 대체재 | 0.6 | Power BI ↔ Tableau, AWS ↔ GCP, MySQL ↔ MariaDB |
| 상위 역량 → 하위 기술 | 0.5 | SQL 경험 → PostgreSQL 요구 |
| 관련 기술 | 0.3 | Docker → Kubernetes, Git ↔ GitHub |

- 관계는 `P1_skill_layer_final.csv`에 있는 것만 쓴다(`상위_역량_idx`, `대체재_그룹`, `관련_기술` 열).
- **한 단계 관계만** 인정한다. 예: PostgreSQL → SQL → MySQL처럼 두 번 건너뛰지 않는다.
- 연차가 붙은 필수 요건("3+ years of Tableau")에 대체재로 대응하면 충족값은 최대 0.5다.
- 한 요건에 사용자 역량 여러 개가 대응하면 가장 높은 충족값을 쓴다.

**공고 단위**
```
[필수·우대 구분이 있는 공고]
  역량 적합도 = 필수 평균 × 0.7 + 우대 평균 × 0.3
    · 우대 없음 → 필수 평균 × 1.0
    · 필수 없음 → 우대 평균 × 0.6 + 업무 언급 평균 × 0.4

[구분이 없는 공고]
  역량 적합도 = (업무 언급 + 판정 불가) 요구 역량의 충족값 평균

역량 점수 = 역량 적합도 × 60
필수 충족률 = 충족값 0.5 이상인 필수 요건 수 ÷ 필수 요건 수
```
- 1단계의 빼는 규칙은 여기에도 그대로 적용한다.
- 필수 0.7 : 우대 0.3은 1·2단계의 2 : 1(약 0.67 : 0.33)과 거의 같은 비율이다.
- 구분 없는 공고 규칙이 필요한 이유: Kaggle 공고 중 필수 문구가 탐지된 공고는 717건뿐이라, 대부분이 여기에 해당한다.

### 3.3 직무 일치도 (15점)

| 공고 직무군 | 점수 |
|---|---|
| 사용자 1지망 | 15 |
| 2지망 | 12 |
| 3지망 | 10 |
| 인접 직무군 | 6 |

인접 직무군: 데이터·AI ↔ 소프트웨어 / 마케팅 ↔ 영업 ↔ 기획 / 고객지원 ↔ 운영 ↔ 영업 / 디자인 ↔ 기획 ↔ 마케팅 / 인사 ↔ 운영 / 재무·법무 ↔ 운영

### 3.4 경력 적합도 (15점)

| 공고 경력 판정 | 점수 |
|---|---|
| A 신입·인턴 | 15 |
| B 경력 명시 1년 / 2년 / 3년 | 14 / 11 / 7 |
| D2 불명확 | 9 |
| D1 mid 추정 | 5 |
| C 4년 이상·시니어 | 후보에서 제외(점수 계산 안 함) |

- 사용자 실무 개월 수(경험 카드 중 `is_paid_work = true`인 카드의 기간 합)가 요구 연수 × 12 이상이면 15점이다.

### 3.5 선호 조건 (10점)

| 항목 | 배점 | 기준 |
|---|---|---|
| 근무방식 | 4 | 일치 4 / 공고 정보 없음 2 / 불일치 0 |
| 지역 | 3 | 일치 또는 원격 3 / 공고 정보 없음 1.5 / 불일치 0 |
| 연봉 | 3 | 희망 이상 3 / 공고 정보 없음 1.5 / 미달 0 |

- **사용자가 입력하지 않은 항목은 만점이다.** 입력하지 않았다고 불이익을 주지 않는다.

### 3.6 그룹과 정렬

| 그룹 | 조건 |
|---|---|
| 추천 | 70점 이상 + 필수 충족률 70% 이상 + 분석 신뢰도 high 또는 medium |
| 도전 | 55점 이상이고 추천 조건 일부 미충족 |
| 확인 필요 | 경력 D2, 또는 분석 신뢰도 low |
| 미노출 | 55점 미만, 또는 필수 충족률 50% 미만 |

- 정렬 순서: 점수 → 분석 신뢰도 → 필수 충족률.
- 상위 10건 안에서 같은 기업은 최대 2건까지 보여 준다.
- 화면 이름은 "경험 일치도"다. "합격 확률"로 표현하지 않는다.

### 3.7 손계산 예시 (구현 결과를 이 값과 맞춰 볼 것)

- 공고: 데이터 분석 직무, 신입, 필수·우대 구분 있음
- 사용자: 1지망 데이터 분석, 선호 조건 미입력

| 공고 요구 | 사용자 근거 | 유사도 × 근거 | 충족값 |
|---|---|---|---|
| 필수 Python or R | Python L2 | 1.0 × 0.75 | 0.75 |
| 필수 SQL | PostgreSQL L3 | 0.9 × 1.0 | 0.90 |
| 필수 communication | 의사소통 L2 | 1.0 × 0.75 | 0.75 |
| 우대 Tableau | Power BI L1 | 0.6 × 0.5 | 0.30 |
| 우대 Excel | 없음 | — | 0 |
| (필수 Detail-oriented) | C4 → 계산에서 뺌 | — | — |

```
필수 평균   = (0.75 + 0.90 + 0.75) ÷ 3 = 0.800
우대 평균   = (0.30 + 0) ÷ 2           = 0.150
역량 적합도 = 0.800 × 0.7 + 0.150 × 0.3 = 0.605
역량 점수   = 0.605 × 60               = 36.3

총점 = 36.3 + 직무 15(1지망) + 경력 15(신입) + 선호 10(미입력 = 만점) = 76.3점
필수 충족률 = 3 ÷ 3 = 100%  →  추천 그룹
```
