### P3 경험 카드·인터뷰

- 카드 1장 = 같은 조직 + 같은 기간 + 같은 목적. 파일 하나에서 여러 장이 나오면 사용자 확인.
- 슬롯 값은 모두 `{value, quote, source_id, by}`. **원문 인용이 원문에 있는지 코드가 검사하고, 없으면 버린다.**
- 근거 등급 L0~L3는 **코드가** 판정한다: L3 행동+성과(또는 유효 자격증) 1.0 / L2 행동만 0.75 / L1 수강·도구 이름만 0.5 / L0 저장 안 함. 계수 확정.
- 연결 방식(`match_type`: direct/derived/transferable 등)과 근거 등급은 **별개의 값**으로 둔다.
- 태깅 순서: 사전 규칙(코드) → 규칙에 안 잡힌 문장만 LLM 닫힌 선택(후보 3~5개 중 고르기, `llm_candidate`) → 등급(코드) → 사용자 확인. 사용자가 확인하면 LLM 후보도 점수에 반영.
- 인터뷰: **다음 질문은 코드가 고른다**(역할 → 목적 → 행동 → 성과 빈칸 → 모호 → 등급 올리기 …). LLM은 질문 은행 문장을 바꿔 말하기만 한다. 종료: 핵심 4슬롯 채움 / 질문 8개 / 모름·건너뛰기 연속 3회 / 사용자가 그만.
- 금지 질문: 경력 공백 이유, 나이, 결혼·출산·육아, 건강, 가족 상황, 소득, 종교, 정치.

- 카드 필드는 P3 2.1절 표. 우리 `experience_card_template.json`보다 필드가 많다(`track`, `organization`, `is_paid_work`, `slot_status`, `locked_fields`, `status`, `completeness` 등). P3 작성자는 템플릿 원본을 받지 못했다고 적었다.

**트랙 A · Kaggle 공고 → 공고를 바로 점수화**
