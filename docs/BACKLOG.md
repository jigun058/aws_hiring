# 구현 백로그

나중에 할 구현 작업과 결정을 기다리는 작업을 모은다. 팀원·대회 측과 주고받을 일은 [TEAM.md](TEAM.md)에 두고, 여기에는 코드에서 해야 할 일만 적는다.
끝난 항목은 지우지 않고 상태를 `완료`로 바꾼 뒤 결과를 한 줄 적는다.

상태: `대기`(할 때가 아직 안 옴) · `결정 대기`(팀·사용자 답이 와야 함) · `예정`(다음 작업에 포함) · `안 함`(이번에는 하지 않기로 함) · `완료`
