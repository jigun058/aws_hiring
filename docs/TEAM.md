# 팀 소통 관리

코드 밖의 일(팀원에게 부탁할 것, 대회 측에 확인할 것, 팀원에게 넘길 자료)을 여기서 관리한다.
기능과 로직 설명은 [DESIGN.md](DESIGN.md)에 있다. 팀원에게 설명할 때는 그 문서를 보여 준다.
항목이 끝나면 지우지 말고 상태를 `완료`로 바꾸고 결과를 한 줄 적는다.

상태: `대기`(아직 전달 안 함) · `전달함`(답 기다리는 중) · `회의`(다음 회의 안건) · `완료`

- 대회: AI Bootcamp Innovation Challenger 2026. 주제 "AWS 클라우드 기반 채용시장 기술역량 자동 분석 및 교육과정 추천 AI 에이전트 개발".

- 평가 5항목, 각 20점: 문제해결력, 현장 적용성, 창의성, 전달력, AWS 기술 활용도 및 팀워크.
- AWS 계정에서 실제 호출되는 모델(2026-11-17 확인): Claude Sonnet 4.6 · Sonnet 4.5 · Haiku 4.5, Amazon Nova Pro · Nova Lite · Nova 2 Lite. Claude 5 계열은 계정에서 막혀 있다.

- 문의 창구: 서울시 데이터 지혜, 교육 데이터 서현.
- 공고 근무지: 경기 61%(24,725) · 서울 26%(10,473) · 인천 13%(5,281). "서울시 일자리포털"이지만 **발표에서 "서울 공고"라고 하면 안 된다**(발표 담당에게 전달).
- 공고 원본 데이터 이름: **서울시 일자리포털 채용정보**(사기업 포함). "서울시 일자리포털 공공일자리 정보"가 아니다. 원본은 지혜가 Drive "서울시데이터"에 올림(11/19).
- 발표 자료: 지혜가 15분 발표 초안 `CareerLens_15분발표.pptx`를 공유함(11/19). 서현 의견: 서비스 소개·사용자 스토리는 줄이고 기술·데이터 슬라이드를 늘리자 → D1~D6 자료가 더 필요해질 수 있다.
- 모델 비교를 발표에 넣을지(11/19 대화): 서현은 "물으면 답하기", 지혜는 위험이 커서 반대(검증 과정 중심으로 설명). 태권(구현 담당)이 "성능 시험 뒤에 정하자"로 미룸.
