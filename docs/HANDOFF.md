## 환경

- 구조·명령·배포는 CLAUDE.md에 있다. 다시 배포는 `AWS_PROFILE=tae ./deploy/redeploy.sh`이고, 큰 데이터가 바뀌면 `DATA=1`을 붙인다. 사용자가 푸시한 뒤에 한다.
- AWS SSO는 이 원격 컴퓨터에서 `! aws sso login --profile tae --use-device-code`로 로그인한다. 기본 방식은 127.0.0.1로 넘어가 실패한다. 배포된 서버는 EC2 역할을 쓰므로 로그인 만료와 상관없다.
- 사용자는 원격에서 접속한다. 로컬 서버를 화면으로 보여 줄 때는 Tailscale 주소(`--host 100.118.75.48`)로 띄운다. 다 보면 끈다.
- 화면 확인 스크립트는 `tools/ui-check/`로 옮겼다(쓰는 법은 CLAUDE.md). 배포 사이트 확인은 `BASE=https://d3lowpvdkyf7ly.cloudfront.net node upload.mjs`처럼 한다.

## 확인하지 않은 것

- 배포 사이트에서 합치기 버튼과 "AI가 고른 후보" 표시가 뜨는지(로컬에서는 확인했다. 배포 서버는 새 API가 올라간 것만 확인했다). `BASE=... node upload.mjs`, `pick.mjs`로 볼 수 있다(Bedrock 호출 몇 번).
- 대화창 첫 글자 시간: CloudFront를 거쳐 한 번 재서 2.6초였다(도구를 한 번 부른 질문). 발표 참고 사실에는 "약 2초"로 적혀 있다.
- 추천된 교육과정이 그 역량에 정말 맞는지, 에이전트가 다양한 질문에서 도구를 제대로 고르는지(질문 몇 개만 확인).
