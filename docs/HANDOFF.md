## 확인하지 않은 것

- DLQ 경로: Lambda가 3번 실패 → DLQ → CloudWatch 경보 메일은 실제로 일으켜 보지 않았다. 예외를 올리는 동작만 시험으로 확인했다.

- 수료 판정 기준(`HELD`: 취득했·취득함·합격·땄·보유)은 문장 두 개로만 확인했다. "과정을 수료하고 자격증도 있어요"처럼 수료와 보유를 한 문장에 다른 말로 쓰면 L1로 낮아진다(수료 말이 없는 문장은 그대로 L3).
