## 환경

- 파이썬 가상환경 `.venv`(pandas, scikit-learn, fastapi, boto3 등, `backend/requirements.txt`). 시험 `cd backend && ../.venv/bin/pytest -q`(약 20초), 서버 `../.venv/bin/uvicorn careerlens.api:app --reload`(준비 3.5초).
- 처음 받은 컴퓨터에서는 `backend/data/`에 `careerlens.db`·`courses.json`을 복사하고(`docs/context/assets/drive/`), `scripts/build_engine_inputs.py` → `scripts/analyze_postings.py`(약 3분)를 돌려야 서버가 뜬다.
- AWS: 프로필 `tae`, 서울 리전. SSO 로그인은 `! ~/.local/bin/aws sso login --profile tae --use-device-code` 후 출력된 주소·코드를 브라우저에 직접 입력(자동으로 안 열림). 명령이 백그라운드로 가면 출력 파일을 읽어 주소·코드를 알려 준다.
- Bedrock 실제 확인: `cd backend && AWS_PROFILE=tae ../.venv/bin/python scripts/smoke_llm.py`(호출 약 8번).
- Node·npm 있음(화면 작업용). `rm -rf`는 권한에서 막혀 있다.
