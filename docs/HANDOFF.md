## 확인하지 않은 것

- 수료증 사진을 AI가 "자격증" 유형으로 분류하면, 과정명에 든 자격 이름(예: 요양보호사)이 자격 규칙에 걸려 L3로 붙을 수 있다. 수료는 자격 취득이 아닌데도 그렇다. 원래 있던 동작이고, 이번에 고치지 않았다.
- 수료증 규칙, 팀 규모 질문 삭제, 예시 답 여러 개 고르기를 실제 Bedrock으로 한 바퀴 다 돌려 보지는 않았다. 예시 답 고르기는 배포 사이트에서 확인했다.
- 과정명 맞추기는 문장 10개로만 확인했다. 맞는 과정이 여럿일 때 고른 과정의 역량이 사용자 과정과 정말 같은지는 보지 않았다.
